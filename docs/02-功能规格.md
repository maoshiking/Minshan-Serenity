## 1. 状态机总览

本空间有三个并行的状态机，互不改写对方，只通过环境快照与事件总线通信。

```
                       ┌──────────────────────┐
                       │  环境快照（只读数据）  │
                       │  时间/天气/能见度/节气 │
                       └──────────┬───────────┘
                                  │ 广播
              ┌───────────────────┼───────────────────┐
              ▼                   ▼                   ▼
      ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
      │  访客状态机    │   │  灵猫状态机    │   │  会话状态机    │
      │  idle/touring │   │  idle/walk/…  │   │  closed/       │
      │  /reading/    │   │               │   │  streaming/    │
      │  chatting     │   │               │   │  tool_pending  │
      └───────────────┘   └───────────────┘   └───────────────┘
              │                   │                   │
              └───────────────────┴───────────────────┘
                                  ▼
                      ┌───────────────────────┐
                      │  场景表现层（渲染）     │
                      │  光照/雾/雨雪/相机/UI   │
                      └───────────────────────┘
```

**三条规约**：

1. 灵猫状态机的切换**不得**依赖会话状态机的内部变量，只依赖环境快照与"访客是否在对话中"这一个布尔量。
2. 环境快照只读，任何状态机不得改写它；环境变化由后端或模拟面板产生。
3. 会话状态机**永不打断**灵猫的行走：需要停留时，走的是"请求停驻"，由灵猫状态机自行决定何时蹲下。

## 2. 访客状态机

| 状态 | 进入条件 | 可做的事 | 退出 |
|---|---|---|---|
| `idle` 静止 | 默认；无输入 60 秒 | 观察地形与灵猫 | 任何输入 → 对应状态 |
| `touring` 行路 | 选择了传送目标 | 移动中视角跟随 | 到达 → `idle` |
| `reading` 读卡 | 点击点位热区 | 阅读资料卡、展开出处 | 关闭卡片 → `idle` |
| `chatting` 对话 | 打开对话面板 | 输入与查看回复 | 关闭面板 → `idle` |
| `resting` 静立 | 无输入 ≥ 40 秒 | 什么都不做 | 任何输入 → 对应状态 |

**关键规约**：

- `chatting` 期间**不判定**"静立超时"，避免对话中灵猫又插话。
- `reading` 期间灵猫可以走近并蹲下，但**不主动开口**。
- 从 `resting` 首次进入计时到达 40 秒时，向灵猫状态机发一次"可主动"信号，此后直到访客产生输入为止不再重复发送。

## 3. 灵猫状态机

完整规格见 [frontend/01-导游灵猫-行为规格.md](frontend/01-导游灵猫-行为规格.md)，此处只列状态与进入条件。

| 状态 | 进入条件 | 退出条件 | 能否被对话打断 |
|---|---|---|---|
| `idle` 待机 | 默认 | 有目标路点 / 收到趋近信号 | 否 |
| `walk` 缓步 | 有下一路点 | 到达路点 / 被强制停驻 | 否（走到路点后停） |
| `sit` 蹲坐 | 到达停留点 / 讲解中 | 讲解结束 / 访客离开 | 否 |
| `gaze` 驻足眺望 | 能见度高或黄昏 | 环境变化 | 否 |
| `alert` 警觉 | 访客快速移动或镜头骤变 | 2.5 秒后回落 | 否 |
| `approach` 趋近 | 收到"可主动"信号且冷却已过 | 抵达访客 2–3 米内 → `sit` | 否 |

**禁止**：新增状态必须同步更新本文档与灵猫规格文档；不得在代码里私自加状态。

## 4. 会话状态机

| 状态 | 进入 | 界面表现 | 退出 |
|---|---|---|---|
| `closed` | 默认 | 面板收起，仅有灵猫头顶轻提示 | 访客打开面板 |
| `connecting` | 已发请求，未收到 `session` 事件 | "正在连接"占位 | 收到 `session` → `streaming`；20 秒超时 → `error` |
| `streaming` | 收到 `session` | 文本逐字出现 | 收到 `done` → `closed`；收到 `error` → `error` |
| `tool_pending` | 收到 `tool_call` | 显示工具中文名与转圈（如"正在查天气"） | 收到 `tool_result` → `streaming` |
| `error` | 收到 `error` 事件或超时 | 错误文案 + 重试按钮（`retryable` 为真时） | 重试 → `connecting`；关闭 → `closed` |

**硬性要求**：

| # | 要求 | 理由 |
|---|---|---|
| 1 | `tool_pending` 必须有可见过程态 | 多步工具调用若无过程态，表现为长时间卡死 |
| 2 | 静默 45 秒无任何事件即判卡死并转 `error` | 防止永久 loading |
| 3 | 组件卸载必须 `abort` 流 | 防流泄漏 |
| 4 | 未知事件名必须忽略而非报错 | 后端加事件不应导致前端崩 |
| 5 | `seq` 跳号即判断流，按契约 7.4 重连 | 防文本错乱拼接 |

## 5. 衍生产物（环境 → 表现）

环境快照是唯一输入，衍生产物是唯一输出。中间不得有第三处判断，否则会出现"光变晴了猫还在躲雨"。

| 输入字段 | 衍生产物 A：场景 | 衍生产物 B：灵猫 | 衍生产物 C：文案倾向 |
|---|---|---|---|
| `weather.code = clear` | 硬光、长影、雾极淡 | `gaze` 概率升高 | 讲远山与地理 |
| `cloudy` | 柔光、阴影淡 | 保持当前 | 中性 |
| `overcast` | 灰调、无明确阴影 | 保持当前 | 中性 |
| `rain` / `heavyRain` | 冷调、地面反光、雨丝 | 倾向走向檐下；`walk` 加速 | 讲屋檐、水、水磨 |
| `snow` | 高亮低饱和、雪点、雾中等 | 蜷缩表现；`walk` 减速 | 讲冬与节气 |
| `fog` | 体积雾、光晕弱、远裁剪收紧 | `gaze` 抬头；**不劝人上山** | 讲看云识天，改讲近处 |
| `haze` | 低饱和暖灰、远景灰化 | 保持当前 | 讲近处 |
| `visibilityKm < 5` | 雾浓度上调 | 同上 | 不出行建议 |
| `visibilityKm > 15` | 远景清晰，可开远景提示 | `gaze` 面向远峰 | 讲远山 |
| `time.dayPhase = dusk` | 暖调、影长 | `sit` 概率升高 | 讲归途、收束 |
| `time.dayPhase = night` | 低照度、灯火 | 瞳孔光泽变化、动作放缓 | 讲静、星、夜话 |
| `time.solarElevation` | 光照强度与入射角 | 无直接影响 | 无 |
| `solar.term` | 场景细节（如霜、叶色） | 无直接影响 | 台词素材 |

**验证条款**：改动任一 `weather.code` 后，**光影与灵猫行为必须同时改变**。若只有一项变，说明衍生产物有分叉，属缺陷。

## 6. 验证条款

### 6.1 坐标与数据

| # | 条款 | 验证方法 |
|---|---|---|
| V1 | 全链路只有一套坐标（`1 单位 = 1 米`，`+X 东/+Y 上/+Z 南`） | 代码检索，不得出现第二处经纬度换算 |
| V2 | 每个点位 `world.y` 与其所在地形高度容差 ≤ 0.5 米 | 调试模式渲染竖直标记线，目视贴地 |
| V3 | 路线路点吸附地形后轨迹无跳变 | 播放行走，观察是否有台阶式跳动 |
| V4 | 纹理与高程严格对齐 | 目视核对水系与山脊位置 |
| V5 | 地形加载器完全由元数据驱动 | 替换元数据文件路径后不需改代码 |

### 6.2 灵猫

| # | 条款 | 验证方法 |
|---|---|---|
| V6 | 六状态均有进入与退出条件，无孤立状态 | 状态机日志覆盖全部状态 |
| V7 | 状态切换有过渡，无硬切 | 录屏目视 |
| V8 | 尾与耳的姿态能区分至少四种情绪 | 对照姿态映射表逐项验证 |
| V9 | 主动交互有冷却：一次主动后 120 秒内不再主动 | 计时验证 |
| V10 | 同一话题不重复提起 | 连续触发验证 |
| V11 | 连续三次主动无回应后退化为安静陪伴 | 挂机验证 |
| V12 | 对话进行中永不主动插话 | 对话中挂机验证 |

### 6.3 对话

| # | 条款 | 验证方法 |
|---|---|---|
| V13 | 工具调用过程可见（"正在查天气"） | 操作验证 |
| V14 | 首包 20 秒、静默 45 秒的超时判定生效 | 用 Mock 制造延时 |
| V15 | `seq` 跳号能触发重连且文本不错乱 | Mock 主动跳号 |
| V16 | 未知事件名不导致整轮崩 | Mock 注入未知事件 |
| V17 | 卸载面板后请求被 abort | 网络面板确认 |

### 6.4 内容与文化

| # | 条款 | 验证方法 |
|---|---|---|
| V18 | 未审校内容显示"待核"标记，且不参与知识问答 | 数据检查 + 问答验证 |
| V19 | 每个文化回答可展开出处 | 操作验证 |
| V20 | 无资料时灵猫回答"不确定"而非编造 | 用知识库外的冷门问题测试 |
| V21 | 全站无购买入口、无导流、无分享激励 | 全局检查 |

## 7. 范围蔓延拦截表

新增想法先查这张表。表里有的，按表执行；表里没有的，先改文档再决定。

| 想法 | 判定 | 理由 |
|---|---|---|
| 加个"分享到微信"按钮 | 禁止 | 违反非商业化定位（不诱导分享） |
| 加个纪念品商店 | 禁止 | 直接违反定位 |
| 加个积分/徽章 | 禁止 | 会诱导停留时长，与项目目标相反 |
| 加个用户登录 | P3 之后再议 | 无必要，且引入个人信息合规成本 |
| 让访客自由飞行看全景 | 禁止 | 与 D10 定点停留冲突，破坏叙事 |
| 给灵猫加换装 | 禁止 | 角色不是商品 |
| 加语音合成 | P3 | 需求文档已排期 |
| 加移动端专项优化 | P3 | P1 只保证窄屏可用 |
| 扩域到整条羌道 | P3 | 需先上瓦片分级与 LOD |
| 灵猫多说几句活跃气氛 | 谨慎 | 与"守静"冲突，见需求文档 6.2 |
| 把仪式做成动画表演 | 禁止 | 不把信仰做成表演素材 |
| 加背景音乐自动播放 | 谨慎 | 浏览器会拦截；且需访客显式同意 |

## 8. 功能骨架清单（实现顺序）

按依赖关系排序，每组内可并行。

| 组 | 功能 | 依赖 |
|---|---|---|
| G1 | 类型定义与常量（坐标、事件类型、天气枚举） | 契约 |
| G2 | Mock 数据层（环境、点位、路线、对话流） | 契约 |
| G3 | 地形加载器（元数据驱动）+ 占位地形 | G1 |
| G4 | 视觉设计系统落地（CSS 变量、字阶、基础组件） | 方向 B |
| G5 | 相机与定点停留 + 传送到访 | G3 |
| G6 | 环境快照 → 光影/雾效联动 | G2、G4 |
| G7 | 点位热区与资料卡（含待核标记、出处展开） | G3、G4 |
| G8 | 灵猫程序化模型与六状态机 | G3 |
| G9 | 路点行走、地形贴合、转向平滑 | G8 |
| G10 | 主动交互冷却机制 | G6、G8 |
| G11 | SSE 流式解析与对话面板（含过程态） | G2、G4 |
| G12 | 加载体验、降级、可访问性补丁 | 全部 |

**阻塞说明**：G3 与 G9 在 I1（地名清单）与 I2（DEM 资产）到位前只能使用占位数据，但**不得因此修改接口形态**。占位与真实资产必须走同一套加载路径。
