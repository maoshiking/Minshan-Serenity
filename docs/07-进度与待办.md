## 5. 环境事实（供后续会话参考）

| 项 | 值 |
|---|---|
| 项目根目录 | `Minshan Serenity/` |
| 已装依赖 | vue 3.5.42 / pinia 4.0.3 / vue-router 5.3.1 / element-plus 2.14.7 / @element-plus/icons-vue 2.3.2 / three 0.186.1 / axios 1.20.0 |
| 构建工具 | vite 8.3.4（底层 rolldown） |
| Node / npm | 26.5.0 / 11.17.0 |
| Shell | **Windows PowerShell 5.1**（非 pwsh 7） |
| npm 调用 | `npm.ps1` 被执行策略禁用，必须用 `npm.cmd` |

### 5.1 已踩过的坑（勿重复）

| 坑 | 现象 | 应对 |
|---|---|---|
| rolldown 的 `manualChunks` | 对象形式直接构建失败（`manualChunks is not a function`） | 只能用函数形式 |
| PowerShell 5.1 编码 | `Set-Content -Encoding UTF8` 带 BOM，读回中文可能花屏 | 注意 BOM；用 read 工具核对而非靠控制台显示 |
| 写文件偶发 EIO | `ReplaceFileW EIO (Win32 32)` | 属瞬时锁，稍后重试即可 |
| 按需导入的 dev 请求风暴 | element-plus 子模块请求过多 | `optimizeDeps.include` 预打包 |
| unplugin 生成的类型声明 | 被生成到 `src/types/` | 需提交进仓库，并在 `jsconfig.json` 的 `include` 中声明 |
