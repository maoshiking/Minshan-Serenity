# 后端能力清单

> 交给后端团队的输入。本文档说明**要有哪些能力**与**责任边界**，不规定语言与框架。
> 接口字段以 [../API_CONTRACT.md](../API_CONTRACT.md) 为准。

---

## 1. 责任边界

| 由后端负责 | 由前端负责 |
|---|---|
| 模型调用（豆包多模态与文本）与密钥保管 | 表现与会话编排 |
| RAG：知识库准入、切分、向量化、检索、重排 | 渲染引用与"依据"展开 |
| 工具注册与执行（天气、点位、路线、时间、知识检索） | 展示工具调用过程态 |
| 规划器与任务状态机 | 展示步骤进度 |
| 会话记忆的存储与摘要 | 会话面板交互 |
| 成本控制（限流、配额、缓存、审计） | 断流重试与降级 |
| 内容输出兜底审核 | 不自行拼装或改写模型输出 |

**一条硬边界**：前端**不得**持有任何模型密钥，也不得直接请求模型服务商域名。所有模型调用必须经过后端。

## 2. 能力清单

### 2.1 P1 必须具备

| 能力 | 说明 | 难度 |
|---|---|---|
| 环境快照服务 | 按时间与位置生成环境数据，带缓存；P1 可返回模拟值，但字段必须与契约一致 | 低 |
| 点位与路线服务 | 从配置或数据库读取点位与路线，坐标为 world | 低 |
| 流式对话 | SSE，事件类型必须覆盖契约第 7.3 节全部类型 | **高** |
| 健康检查 | 供前端判断后端是否就绪 | 低 |
| 静态资源托管 | 地形高程与纹理文件 | 低 |

### 2.2 P2 必须具备

| 能力 | 说明 | 难点 |
|---|---|---|
| 知识库准入 | 只接受已审校内容；每条带 source 与 confidence | 流程而非技术难点 |
| 检索与重排 | 向量召回 + 重排；返回可直接展示的片段与出处 | 重排质量决定可信度 |
| 引用回链 | 回答与原文片段的关联关系可查询 | 需设计引用的数据结构 |
| 工具注册表 | 工具的名称、参数、权限、超时、审计 | 需可观测 |
| 规划器 | 多步任务的拆解与执行；失败可重规划 | **高** |
| 视觉模型接入 | 图片上传、模型调用、结果与文化条目对齐 | 需处理大图与超时 |
| 会话记忆 | 上下文压缩、摘要、跨会话记忆 | 需定记忆写入与淘汰策略 |

## 3. 必须自行解决的四件事

### 3.1 检索质量

| 项 | 要求 |
|---|---|
| 切分粒度 | 以"一条文化表述"为最小单元，不要按固定字数硬切 |
| 召回 | 先宽后精：向量召回 + 关键词兜底 |
| 重排 | 必须做，否则出处常常不相关 |
| 出处 | 每条结果必须带来源与原文片段，不能只有分数 |
| 拒答 | 检索置信度低时必须允许模型说"不确定"，禁止强行作答 |

**拒答是功能，不是缺陷。** 文化内容讲错比不讲更糟，这条要写进系统提示词。

### 3.2 模型调用封装

| 项 | 要求 |
|---|---|
| 多模态 | 图片与文本走同一会话上下文 |
| 流式 | 必须支持逐块输出，且能在工具调用前后插入事件 |
| 重试 | 幂等重试；不可重试的错误直接上报 |
| 超时 | 与契约约定一致（首包 20 秒、静默 45 秒） |
| 降级 | 模型不可用时返回 `50001`，而非静默失败 |

### 3.3 提示词分层

四层，从外到内，后者不能覆盖前者：

| 层 | 内容 | 谁维护 |
|---|---|---|
| 人格层 | 灵猫的口吻、节奏、克制原则 | 前端提出，后端落地 |
| 文化约束层 | 不编造、必须承认不确定、不把信仰做成表演 | **文化顾问审核** |
| 环境层 | 当前时间/天气/能见度/节气，用于"看天说话" | 后端注入 |
| 任务层 | 本轮访客的具体问题与任务拆解 | 运行时生成 |

**文化约束层不得由模型自行改写。** 建议：该层内容置于系统提示词最前部，并在输出后做一次规则校验（例如命中"据我所知/肯定是/一定是"等断言式表述且无引用时，要求重答）。

### 3.4 成本控制

| 手段 | 说明 |
|---|---|
| 轮数上限 | 单轮会话最多 N 次模型调用，超出明确告知 |
| token 上限 | 上下文超限时按摘要压缩，不截断到语义破碎 |
| 工具结果复用 | 同一环境快照下天气等结果复用，不重复调用 |
| 响应缓存 | 相同问题在同一环境下可复用回答 |
| 审计 | 每次工具调用与模型调用留痕（工具名、耗时、成败、token 估算） |

## 4. 数据存储需求

| 数据 | 必要性 | 说明 |
|---|---|---|
| 文化知识条目 | P2 必须 | 原文、来源、信度、标签、向量 |
| 点位与路线 | P1 必须 | 可从配置文件起步 |
| 会话记录 | P2 建议 | 供记忆与审计 |
| 工具调用审计 | P2 必须 | 可观测性基础 |
| 环境快照缓存 | P1 必须 | 10 分钟量级 |

**合规提醒**：不采集非必要个人信息。会话记录若含可识别信息，需定保存期限与脱敏策略。

## 5. 待确认事项

| # | 待确认 | 影响 |
|---|---|---|
| 1 | 契约第 7.3 节的 SSE 事件类型是否全部可实现 | 决定对话过程态能否做出来 |
| 2 | 环境数据源与许可（P2） | 决定能否接真实天气 |
| 3 | 模型服务商与配额 | 决定限流策略与成本上限 |
| 4 | 服务器规格与并发预期 | 决定缓存与限流参数 |
| 5 | 静态资源托管方式（地形文件走 CDN 还是应用服务器） | 决定前端加载策略 |
