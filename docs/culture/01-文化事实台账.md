## 0. 使用规则

| 规则 | 说明 |
|---|---|
| 未核不写 | `待核` 内容不得写成代码里的真实数据；只能做占位 |
| 占位可辨 | 占位数据必须一眼可辨（名称含"占位"、`verified: false`） |
| 出处必填 | 每条核销内容必须给出处，无可追溯出处的表述不予收录 |
| 一律不猜 | 我方在受限环境内无法联网核实（`web_search` 与 `web_fetch` 均不可用），故本文档的"待核"栏可能包含我方完全不掌握的信息 |
| 宁可少讲 | 少一个点位不会损伤项目，多一句错话会 |
