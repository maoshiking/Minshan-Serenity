# 导游灵猫 · 行为规格

> 灵猫是本项目最有记忆点、也最容易做砸的部分。
> 本规格的两个核心判断：**它靠姿态说话，靠冷却"守静"**。

---

## 1. 形象定义

| 项 | 规定 |
|---|---|
| 本质 | 抽象化猫形，水墨或留白剪影为骨 |
| 品种特征 | **不得有**（不指定毛色、不指定品种、不做拟人化服装） |
| 与场景的关系 | 与真实地形同场渲染，靠材质与光区分"它是化身" |
| 尺寸 | 与真实猫接近，肩高约 0.25 米；不放大成吉祥物体型 |
| 材质方向 | 剪影主体 + 极轻边缘光；不追求毛发渲染 |
| 影子 | 必须有。没有影子它就不在地面上 |
| 40 米外 | 渲染为光点或简化剪影（性能） |

### 1.1 硬约束

**不得将羌族宗教或信仰类纹样（白石、羊角、法器符号等）用于灵猫身上。** 猫是角色，不是法器。

**待核**：猫在羌族文化中的位置由文化顾问确认；确认前不建立任何相关性表述。

---

## 2. 程序化动画规格

不使用骨骼资产。全部由节点变换实现：身体根节点、躯干、头、两耳、尾（5 节）、四足。

### 2.1 姿态映射（情绪的唯一表达手段）

猫没有可读的面部表情，**情绪全靠姿态与尾巴**。这张表是硬规格。

| 情绪 | 尾巴 | 耳朵 | 身体 | 用法 |
|---|---|---|---|---|
| 放松 | 尾尖缓慢轻摆（振幅小、频率低） | 正立微前 | 呼吸起伏平缓 | `idle` |
| 好奇 | 尾巴中段抬起，尾尖小幅度快速摆动 | 朝声音方向转 | 前倾，重心靠前 | `gaze`、察觉访客 |
| 警戒 | 尾巴竖起，整体僵直 | 后压 | 身体压低，重心后坐 | `alert` |
| 不安 | 尾巴夹低，贴身后 | 完全后压 | 蜷缩，体积缩小 | 雷雨、强风、访客快速逼近 |
| 亲近 | 尾巴竖起且尾尖微弯（近似问号形） | 正立 | 主动靠近，步频略快 | `approach` |
| 久留 | 尾巴绕身，尾尖搭在前爪 | 放松下垂 | 完全静止，仅呼吸 | `sit` 长时间停留 |

**验证**：六种情绪至少两两可辨（见 [../02-功能规格.md](../02-功能规格.md) V8）。

### 2.2 六种动作

| 动作 | 实现要点 | 用于 |
|---|---|---|
| 呼吸 | 躯干 `scaleY` 极缓波动（周期约 3.2 秒） | 所有状态的基础层 |
| 缓步 | 四足交替 + 脊柱正弦波动 + 头部轻微上下 | `walk` |
| 小跑 | 步频加倍，身体起伏加大，尾巴抬高 | `approach` |
| 蹲坐 | 后肢收拢，前肢并拢，身体高度下降约 40% | `sit` |
| 甩尾 | 尾节依次延迟摆动（相位差） | 情绪切换的过渡 |
| 耳动 | 耳朵绕基部小幅旋转 | 被声音或环境变化触发 |

**过渡要求**：任意两个状态之间必须有过渡（建议 0.3–0.6 秒插值），**不得硬切**（见 V7）。

## 3. 移动规格

### 3.1 沿路点行走

| 项 | 规定 |
|---|---|
| 路径来源 | 路线的 `waypoints`（world 坐标） |
| 平滑 | 路点之间用平滑曲线连接，不直连折线 |
| 贴地 | 位置 `y` 实时吸附地形高度（容差 ≤ 0.5 米，见契约 2.6） |
| 坡度适应 | 上坡时身体前倾、步频略降；下坡时身体后仰、步幅略增 |
| 转向 | **朝向与移动方向之间保留延迟**（约 0.25 秒插值），这是"活物感"的关键 |
| 停驻 | 到达 `stops` 中登记的停留点时进入 `sit`，停留 `dwellSeconds` |

### 3.2 速度

| 情形 | 速度 |
|---|---|
| 缓步 | 0.8 m/s |
| 趋近访客 | 1.6 m/s |
| 雨天 / 雪天 | 缓步 × 1.25（想快些到檐下） |
| 上坡 | × 0.75 |
| 下坡 | × 0.9 |

### 3.3 禁忌

| 禁忌 | 原因 |
|---|---|
| 不做物理碰撞与跳跃 | 真实地形上物理结算易出滑稽错误；用"绕行 + 高度吸附"即可 |
| 不穿模岩体 | 路点必须由文化/地理侧核对，避开山体 |
| 不在访客正前方急停 | 会显得像卡住 |

## 4. 主动交互与冷却机制

**这一节是"守静"的技术实现。懂得闭嘴比会说话更重要。**

### 4.1 触发条件（全部满足才允许）

| 条件 | 阈值 |
|---|---|
| 访客状态为 `resting`（静立） | 无输入 ≥ 40 秒 |
| 未处于冷却窗口 | 上次主动后 ≥ 120 秒 |
| 访客未在对话中 | `chatting` 状态直接否决 |
| 同一话题未提过 | 话题去重 |
| 连续主动未达上限 | < 3 次 |
| 灵猫自身可打扰 | 不在 `alert`、不在行走中途 |

### 4.2 冷却状态机

```
        访客静立 40 秒
              │
              ▼
      ┌───────────────┐
      │  资格判定      │──不合格──► 等待（不重置计时）
      └───────┬───────┘
              │ 合格
              ▼
      ┌───────────────┐
      │ approach 趋近  │
      └───────┬───────┘
              ▼
      ┌───────────────┐
      │  sit 说一句    │
      └───────┬───────┘
              ▼
      ┌───────────────┐
      │ 120 秒冷却     │
      └───────┬───────┘
              │ 访客仍无回应
              ▼
        主动次数 +1
              │
        ┌─────┴─────┐
        │           │
      < 3 次      = 3 次
        │           │
        ▼           ▼
     可再主动   退化为安静陪伴
                （不再开口，仅蹲坐于旁）
```

### 4.3 两条必须遵守的规约

1. **"退化为安静陪伴"不是失败态，而是设计态。** 连续三次主动无回应，说明访客想安静地看，此时继续搭话就是骚扰。灵猫蹲下陪着，这本身就是"守静"。
2. **对话进行中永不主动插话**，无论静立多久。

### 4.4 主动开场白的取材顺序

| 优先级 | 取材 | 例子（占位，非真实内容） |
|---|---|---|
| 1 | 当下环境变化 | 雾起了、能见度降了 |
| 2 | 访客所在地点 | 附近有一个待核点位的方位 |
| 3 | 时间与节气 | 天将黑、节气将至 |
| 4 | 访客此前的提问 | 延续之前的话题 |
| 5 | 兜底静默 | **宁可不说** |

**第 5 条很重要**：没有合适的取材就不开口，这不算功能缺失。

## 5. 言谈举止规格

| 项 | 规定 |
|---|---|
| 口吻 | 克制、具体、不抒情、不用感叹号堆叠 |
| 句长 | 单次回复建议不超过 3 句，除非访客明确要求展开 |
| 自称 | 不使用"本导览""小助手"等产品化自称 |
| 不确定 | 必须直说"这个我不确定"，禁止模糊化带过 |
| 出处 | 涉及文化事实时给出处，可展开 |
| 禁止 | 编造、夸大、把信仰内容做成表演、使用网络流行语 |
| 表情符号 | 不使用 emoji；界面图标使用 Element Plus 图标库 |

---

## 6. 与其它模块的接口

| 交互方 | 交互内容 | 规约 |
|---|---|---|
| 环境快照 | 读取天气、能见度、时间、节气 | 只读，不改写 |
| 会话状态机 | 接收"访客是否在对话中"布尔量 | 只读一个布尔量，不读会话内部状态 |
| 访客状态机 | 接收"可主动"信号 | 每次进入 `resting` 只发一次 |
| 场景表现层 | 输出位置、朝向、姿态参数 | 不直接修改光照或雾 |
| 资料卡 | 被点位点击驱动走近并蹲下 | 走近但**不主动开口** |

---

## 7. 验收要点

| # | 要点 |
|---|---|
| 1 | 六状态齐全，无孤立状态，均有进入与退出条件 |
| 2 | 状态切换有 0.3–0.6 秒过渡，无硬切 |
| 3 | 六种情绪姿态两两可辨 |
| 4 | 转向有延迟，行走无贴地跳变 |
| 5 | 主动交互冷却 120 秒且话题去重 |
| 6 | 连续三次无回应后退化为安静陪伴 |
| 7 | 对话中永不插话 |
| 8 | 无任何羌族信仰类纹样 |
| 9 | 40 米外自动简化渲染 |
