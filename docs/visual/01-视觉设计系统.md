# 视觉设计系统 · 方向 B「山志」

> 方向：杂志编辑风格（Editorial）+ 建档语汇。
> 依据：美学库 `Skills/前端美学设计技能/`。**该库存在多处自相矛盾，本文档按其自身结论"认方向、不照抄字体名"落地。**

---

## 1. 为什么是「山志」

| 判断依据 | 说明 |
|---|---|
| 内容性质 | 已定决策 D7：内容必须可溯源。B 是唯一把"有出处"变成设计语言的方案 |
| 记忆点 | **点开任意一点，出来的是"资料卡"而不是"景点介绍"**：左侧文献出处与年代，右侧今日实景 |
| 气质匹配 | 建档、郑重、可查，与"非商业化文化空间"的身份一致 |
| 执行风险 | 中（低于 A 的水墨细节易垮、C 的偏斜执行） |

### 1.1 差异化自问（美学库开工四问之四）

| 问题 | 回答 |
|---|---|
| 目的 | 让访客相信这里说的每句话都有依据 |
| 调性 | 杂志编辑 × 建档，一个极端方向，不折中 |
| 约束 | Three.js 实时渲染、首屏 3 秒、中文排版、非商业化 |
| 差异化 | **人们会记住的那一件事：每一条文化表述旁边都挂着它的出处，连灵猫不确定时也会直说。** |

## 2. 色彩

### 2.1 主色板

| 角色 | 名称 | hex | 占比 | 用途 |
|---|---|---|---|---|
| 主色 | 石墨 | `#22262B` | 60% | 页面底、空间外的界面底、正文文字（浅底时） |
| 次色 | 青灰 | `#5C6B73` | 30% | 次级文字、分隔、未激活态、网格线 |
| 基色 | 纸白 | `#F2F0EB` | 10% | 资料卡纸面、关键文字（深底时） |
| 点缀 | 朱砂 | `#B4453A` | **< 2%** | 仅用于：当前选中点位、日期标记、信度警示。**不得用于大色块** |

### 2.2 支撑色（仅数据与状态，不参与视觉主调）

| 名称 | hex | 用途 |
|---|---|---|
| 高程低 | `#2A3036` | 等高分层、海拔标尺底 |
| 高程高 | `#7E8B93` | 等高分层、海拔标尺顶 |
| 已审校 | `#4F6B5A` | 信度标记"已审校" |
| 待核 | `#B4453A` | 信度标记"待核"（复用点缀色） |

配色遵循美学库两条原则：**单一主色 + 锐利点缀**优于平均分布；**用 CSS 变量保持一致**。

### 2.3 对比度

| 组合 | 对比度（约） | 用途判定 |
|---|---|---|
| 纸白 `#F2F0EB` on 石墨 `#22262B` | 约 13:1 | 正文可用 |
| 青灰 `#5C6B73` on 纸白 `#F2F0EB` | **约 4.0:1** | **仅限大字号或次级信息**，不得用于正文 |
| 朱砂 `#B4453A` on 纸白 `#F2F0EB` | 约 4.8:1 | 可用于短标签，不可用于长文本 |

**待办**：实现时用工具实测并回填精确值；青灰若用于正文必须加深。

## 3. 字体

### 3.1 字体栈

| 角色 | 首选 | 降级链 | 授权 |
|---|---|---|---|
| 展示体（中文） | `Source Han Serif SC` | `Noto Serif SC`, `Songti SC`, `SimSun`, serif | SIL OFL，可自托管 |
| 正文（中文） | `IBM Plex Sans SC` | `Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, `Hiragino Sans GB`, sans-serif | SIL OFL，可自托管 |
| 数据（数字与编号） | `JetBrains Mono` | `Cascadia Mono`, `Consolas`, monospace | SIL OFL，可自托管 |

**关键警告**：中文**屏显**宋体在 Windows 上会退化到宋体（SimSun），笔画会崩。所以展示体**必须自托管子集**，不能只写字体名。

### 3.2 字阶（极端对比是方向核心）

| 层级 | 字号 | 字重 | 字距 | 行高 | 用途 |
|---|---|---|---|---|---|
| `display` | `clamp(32px, 5vw, 52px)` | 700 | `-0.02em` | 1.15 | 点位名、页面主标题 |
| `title` | 24px | 600 | `-0.01em` | 1.3 | 资料卡标题 |
| `subtitle` | 18px | 500 | 0 | 1.5 | 段落小标题 |
| `body` | 15px | 400 | 0 | 1.75 | 正文 |
| `caption` | 13px | 400 | `0.01em` | 1.6 | 出处、年代 |
| `label` | 11px | 500 | `0.12em` | 1.4 | 栏目标签、信度标记（**必须大写或加宽字距**） |
| `data` | 13px | 400 | 0 | 1.4 | 坐标、海拔、文献编号（等宽） |

**极端对比的落实**：`display` 与 `body` 字号比超过 3 倍。这是"杂志编辑"方向不可妥协的一条。

### 3.3 排版规则

| 规则 | 内容 |
|---|---|
| 中文行高 | 正文 1.75，比英文排版更宽松 |
| 中西文混排 | 中文与拉丁字母之间加 `0.05em` 间隙 |
| 避头尾 | 标点不得出现在行首 |
| 段落缩进 | 不用首行缩进，用段间距（杂志习惯） |
| 首字下沉 | 仅用于长文献原文引用，一页最多一处 |
| 数字 | 一律等宽字体，便于竖向对齐 |
| 禁止 | 用 Inter / Roboto / Arial / 系统字体当主角（美学库黑名单） |

## 4. 间距与栅格

| 项 | 值 |
|---|---|
| 基础单位 | 8px |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 |
| 内容最大宽度 | 1280px |
| 正文行宽 | 约 34 个中文字（超宽行损害可读性） |
| 栏布局 | 资料卡为不对称双栏（左 1 : 右 2），左栏窄、右栏宽 |
| 圆角 | 2px（档案语汇要**近似直角**，不用大圆角） |
| 分隔 | 1px 细线为主，咨询 `#5C6B73` 的 30% 透明 |

**反普通的一条**：不做卡片墙。资料卡是"纸面"，不是"卡片"——不用投影浮起，用细线框与纸面色块区分层次。

## 5. 动效

| 变量 | 值 | 用途 |
|---|---|---|
| `--ease-page` | `cubic-bezier(0.76, 0, 0.24, 1)` | 主缓动，档案翻页感 |
| `--ease-out-expo` | `cubic-bezier(0.16, 1, 0.3, 1)` | 入场揭示 |
| 时长 | 200ms（微交互）/ 320ms（面板）/ 480ms（入场） | |

### 5.1 动效原则

| 原则 | 落实 |
|---|---|
| 每个动画都要有理由 | 出场动画只用于"揭示新信息"，不做装饰 |
| **一次错开编排的入场 > 一堆零散微交互** | 首次进入空间时，标题、资料卡、点位标签按 0.1s 阶梯错开 |
| 只动 `transform` 与 `opacity` | 禁止动 width / height / margin / top / left（美学库性能黑名单） |
| 尊重减少动效偏好 | `prefers-reduced-motion` 时取消位移，仅保留透明度 |
| 禁纯装饰动效 | 无背景循环动画、无闪烁、无持续跳动 |

### 5.2 空间内动效的特殊约定

| 项 | 约定 |
|---|---|
| UI 面板 | 320ms 滑入，位移 ≤ 24px |
| 资料卡展开 | 内容整体淡入 + 轻微上移，不做逐字打字机（打字机只用于灵猫的话） |
| 灵猫的话 | 逐字出现，速度约每字 40ms |
| 镜头移动 | 缓入缓出，最短 600ms，不做瞬间跳切 |
| 环境切换（天气变化） | 光影过渡不少于 1.2 秒，避免突兀 |

## 6. 灵猫（角色）的视觉调性

| 项 | 规定 |
|---|---|
| 材质 | 水墨或留白剪影为骨；与真实地形同场渲染 |
| 边缘 | 极轻的边缘光，用于在深色地形上保持可辨 |
| 影子 | 必须有 |
| 情绪 | 只用姿态与尾巴表达，不做拟人化表情 |
| 纹样 | **禁止使用任何羌族信仰类纹样**（白石、羊角、法器符号） |
| 尺寸 | 与真实猫接近，不放大成吉祥物体型 |
| 与主色的关系 | 猫是画面里唯一可以"吃掉"朱砂点缀的角色（例如眼部极小的朱砂点），朱砂的稀缺性由此强化 |

## 7. 组件规格（关键几件）

| 组件 | 规格要点 |
|---|---|
| 空间标签（点位） | 1px 细线指引 + `label` 字号；悬停时线变亮、标签展开名称；不做气泡 |
| 资料卡 | 纸白底、2px 圆角、细线框；左栏为出处与年代、右栏为正文与图；**顶部固定信度标记** |
| 信度标记 | `已审校` 用绿 `#4F6B5A`；`待核` 用朱砂并附一句"此条尚未核校" |
| 出处折叠 | 默认收起，展开后显示原文片段与文献编号；用 `data` 字号 |
| 对话面板 | 深底、等宽数据行显示工具调用（如 `查天气 · 进行中`），文本用正文衬线 |
| 工具栏 | 图标一律用 Element Plus 图标库；**禁用 emoji** |
| 环境指示 | 右上角常驻：时间 · 天气 · 温度 · 能见度；等宽数字，竖向对齐 |
| 加载态 | 细线进度 + 文字说明正在加载什么；不用跳跃动画 |

## 8. 反 AI-slop 自检（逐条对账）

| 黑名单项 | 本方案 |
|---|---|
| 白底紫渐变 | 无 |
| 蓝 → 青渐变 | 无 |
| 泛滥 `#6366F1` | 无 |
| Inter / Roboto / Arial 当主角 | 无（展示体为宋体，正文为 IBM Plex Sans SC） |
| 系统字体当主角 | 不作为主角，仅作降级链末端 |
| Space Grotesk | 未使用 |
| 可预测的布局 | 资料卡为不对称双栏，非卡片墙 |
| 每个设计都长得一样 | 采用建档语汇，与其他项目区分 |
| 纯装饰性闪烁跳动 | 无 |
| 过度 loading 动画 | 细线进度 + 文字说明 |
